##  Descrição

Este projeto foi desenvolvido como parte dos meus estudos em **Quality Assurance (QA)**, utilizando o **Cypress** para automação de testes web.  
O objetivo é validar funcionalidades do site (https://automationpratice.com.br), explorando cenarios reais como login, cadastro, carrinho e checkout.

---

##  Tecnologias utilizadas

  **JavaScript (ES6+)**  
  **Node.js**  
  **Cypress**  
  **VS Code**  
  **Git & GitHub**

---

##  Conceitos aplicados

 • Criação de **cenarios de teste automatizados**  
 • Uso de **locators dinâmicos** (XPath, CSS selectors)  
 • Estrutura de **Page Objects**  
 • Testes de **UI e fluxo de usuário**  
 • Execução em modo **headless e interativo**  

---

## Aprendizados

Durante este projeto, desenvolvi habilidades em:

• Criação de testes automatizados eficientes  
• Interpretação e depuração de erros  
• Melhoria contínua da cobertura de testes  
• Organização de código com boas práticas de QA  

---

##  Como executar o projeto

```bash
# Clonar o repositório
git clone https://github.com/JoaoVictorcds/Automacao-Web-Cypress.git

# Acessar a pasta do projeto
cd automacao-web-cypress

# Instalar as dependências
npm install

# Rodar os testes com interface
npx cypress open

# Rodar os testes em modo headless (sem abrir navegador)
npx cypress run
```
